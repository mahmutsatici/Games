# Games

Monorepo of original HTML5 web games.

| Game | Folder | Description |
|------|--------|-------------|
| Moon Cargo (Ay Kargo) | [`ay-kargo/`](ay-kargo/) | Text-free physics driving game: deliver loose crates across the Moon, Mars and an ice moon. |
| Sucuk Hop (Zıp Sucuk) | [`zip-sucuk/`](zip-sucuk/) | One-button physics game: an elastic sucuk hops through a giant kitchen. Hold to charge, release to hop; the end that lands sticks. |

Each game is a self-contained Vite + TypeScript project (static files only, no backend).
